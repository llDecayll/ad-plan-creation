# A1 Shaant: plan (run r1)

Not done live: Ad Library, Transparency, policy search, store data, ₹/£ (assumed ₹110).

## 1. Real outcome and economics
- Outcome: paying annual subscriber. Transaction happens in Apple/Google billing; platforms see only install/trial_start (once linked). Reconcile purchases weekly from store consoles/AppsFlyer.
- India: LTV ₹1,150 (assumed net of 15% store cut). Break-even per paying user ₹1,150; per trial 0.18 x 1,150 = ₹207. History: ₹14 CPI / 0.4% = ₹3,500 per trial (17x break-even).
- UK: break-even per trial 0.31 x £33 = £10.2.

## 2. Goal translation
- "Max installs" declined as the goal; optimise trial_start, judge on paying subscribers. Installs are a diagnostic.
- Declined: condition targeting and "Are you depressed? Shaant can cure it" (health personal-attribute policy, cure claim). Alternative: broad/Advantage+ audiences with proxy signals (sleep, meditation, yoga); benefit copy ("Wind down in 10 minutes. 7 days free"); no cure claims.

## 3. Platform split
₹2,50,000 = ₹8,224/day. Google ₹4,200 (52.5%) + Meta ₹3,800 (47.5%) = ₹8,000 x 30.4 = ₹2,43,200; ₹6,800 buffer for festive CPM (Diwali ~8 Nov, +20-40%). No outcome history, so intent order: Google has Play search demand; the old failure was the install event, not the channel. Meta gets a near-equal share for its Reels assets.

## 5. Deferred and other channels
- **UK diaspora (Meta, Android+iOS):** derived CPI £2.5-6, trial cost ~£23 (£15-40), cost per paying ~£74 vs LTV £33 (loses money). Learning-limited 3 x £23 = £69/day (~₹7,600) is above the 20% test cap (₹1,640/day), so defer. Proper unit 7x = £161/day (~₹17,700). Client decides; trigger: India cost per trial <= ₹207 for 30 days.
- **India iOS:** needs SKAN conversion-value schema first (zero spend); then ~₹2,500/day standalone unit.
- **Other channels:** Apple Search Ads, store listing optimisation (free), creator/partnership ads, push/email to non-converting trials.

## 6. Policy / special category
Meta special ad category: none (wellness; India is not a required region; do not opt in). No securities declaration. Health: no condition targeting (Meta removed it; Google bans it), no cure or mental-health outcome claims; competitor hook "Struggling with anxiety?" is personal-attribute phrasing, so avoid. Baseline, not checked live.

## 7. Operating constraints
In-app chat only; ads always-on, no schedule. Trial resolves on day 7, so paid reads lag 7 days.

## 8. Key risks / blockers
1. Firebase events not linked to Google/Meta: launch gate (Google link same day; Meta via AppsFlyer/Meta SDK, then test events).
2. Thin economics (above).
3. 0.4% install-to-trial is 25x below the 10% floor: suspect onboarding/paywall as well as Tier-3 traffic. Ask for the install > onboarding > paywall funnel.
4. Tier-3 junk can recur on Google; check the city split at day 3.
5. LTV net/gross unconfirmed. 6. Mental-health policy rejections.
