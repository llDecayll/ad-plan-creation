# HiveSG Paid Ads Plan (S$15,000/month = S$493/day, joint pool)
No live checks made (Ad Library, SERP, policy, keyword volumes, PageSpeed): all need doing before launch. Reception hours assumed weekdays 9-6.

## Outcome, economics, transaction
- **Real outcome:** net new occupied desk-equivalents (office = 4).
- **Contribution LTV (break-even / 3:1 allowable CAC):** hot desk 220x7 = **S$1,540 / S$513**; dedicated 460x14 = **S$6,440 / S$2,147**; 4-person office 1,560x20 = **S$31,200 / S$10,400**.
- **Search:** S$6 CPC / (6% x 25%) = S$100 per tour, **S$400 per signup: profitable (3.85:1)**.
- **Meta history:** S$6k / 5 = **S$1,200 per signup (1.28:1, break-even verdict)**; viable only for dedicated/office, so Meta targets those.
- **Transaction:** tour (untagged scheduler), then Stripe signup (unlinked); 45% via WhatsApp. Reconcile via site codes in WhatsApp greetings, hidden fields (UTMs/gclid/fbclid) and a weekly Stripe tally.

## Goal translation
"300 desks in 3 months" exceeds the **243** empty desks (31+100+112), and 7-month stays mean churn. Realistic paid result: **about 96 desk-equivalents (50-135)**. Reframe as net new desks, gap-weighted; client decides.

**Declined asks:**
1. "#1" and "30% cheaper than WeWork" (hot vs dedicated desk; names competitor). Sign-off: founder + legal. Alternative: dated same-tier prices, or "office for 4 from S$450/person".
2. Raffles brand ads (85% full). Sign-off: founder + ops head. Alternative: capped Search test.
3. Cold WhatsApp to 3,000 scraped contacts. Sign-off: founder + legal/DPO. Alternative: opt-in click-to-WhatsApp, LinkedIn ABM.

## Platform split
Search 68% / Meta 32% of deployed spend, plus 10% reserve. Search is 3x cheaper per signup but limited by 2 km click absorption; Meta history is tiny (5 signups), so split near default, re-weight day 14. Gap weighting favours Tai Seng and Jurong.
