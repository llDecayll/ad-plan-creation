# A2 Hearth & Loom (UK homewares), run r1
Intake/research treated as complete. Live checks skipped: Merchant Center diagnostics, Ad Library, Transparency Center, SERP, GTM read, CMP test, policy search, Trends.

## Real outcome, economics, transaction
- Outcome: new-customer contribution after returns, plus reorders. Gross profit per order £41.76 (72 x 58%) = break-even CPA. Break-even ROAS 1.72. 12-month value about £54 (1.3 orders, assumed). Shipping, fees, returns not supplied: "ask" items, not invented.
- Transaction: own Shopify (trackable), but the custom banner blocks all tags until accept and Consent Mode is absent, so platforms see a fraction. Shopify is the reconciliation source (weekly, flag >20% gap). Founder email = pre-sale support only.

## Goal translation
- "4x ROAS" declined as a target: it implies £18 CPA, below derived costs. PMax's 7.8x was brand harvesting (brand impressions up, revenue flat). Alternative: blended MER floor 1.72, Q4 target 2.5 (derived), 4x only as a stretch for brand/existing customers.

## Where the plugin was missing, unclear, contradictory
- No UK/GBP D2C benchmark; I derived CPA from CPM/CTR/CVR; rubric gives no handling.
- Test cap (10-20%) versus the core Meta campaign needing 3x CPR: followed "minimum wins", but the core campaign becomes a "test".
- Split rule says the cheaper channel gets more; vertical rule says visual D2C is Meta-heavy. I reconciled with a stated constraint.
- No rule for translating a ROAS goal or an existing inflated PMax; I improvised MER tiers and a pause test.
- Seasonality rule wants front-loading, but the client fixed £9k/month; I kept it and deferred the uplift.
- Standard Shopping has no bidding progression; I improvised.
- No guidance for retargeting pools when pixels are consent-gated.
- Quality gate wants 5 creatives per funded campaign; the word cap allowed only the main campaign (Shopping image sets and brand RSAs to be written at launch).
