# S1 SmileCraft Dental (quality gate run)
Live checks skipped (policy, SERP, Ad Library, keywords, CPC). All costs are plugin-table benchmarks, derived, +/-50%.

## Real outcome and transaction
- Real outcome: attended consultation that becomes a case (implant, aligner, RCT). Weekday chairs are empty, so the problem is bookings.
- Break-even = close rate x case value x margin. None supplied, so not computed; ask the owner.
- Transaction: WhatsApp, calls, /book form. Platforms see conversation/lead only. Reception tallies booked and attended by campaign code (SC-M1, SC-G1).

## Goal translation
"Awareness" is replaced by bookings; hard-boundary local reach comes with it. Awareness is deferred, not funded. No client ask breaks policy, so nothing is declined.

## Platform split (Rs3,000/day, one pool)
Meta Rs1,650 (55%), Google Search Rs1,350 (45%). Search minimum is funded first (15 clicks x Rs70 = Rs1,050; 4 competitors bid on core terms). Derived cost per attended patient is lower on Meta (~Rs2,100 vs ~Rs3,400) and Meta absorbs more; two-area hard boundary caps search volume. This is below the playbook's 55-70% Search start (see improvised).

## Improvised (plugin gaps)
1. Split: no history means 55-70% Search, but cost-per-outcome favours Meta. I chose 45/55; no tie-break given.
2. Meta scheduling: "schedule only if nobody answers" vs "away message option". Chose away message; no tie-break.
3. No break-even method without margin; intake never asks for it.
4. Funnel anchors fit conversations only; none for calls/forms, reused.
5. Tracking rubric silent on click-to-WhatsApp with an irrelevant verified pixel, or an unknown tally; scored 4 plus cap.
6. CPL method (midpoint CPC / midpoint CVR) unspecified.
7. Two hard-boundary pins vs "prefer one radius".
8. No rule for local-awareness asks; vanity guidance covers followers only.
9. Live checks not possible offline.
